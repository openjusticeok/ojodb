# List the case types present in the OJO database

Returns a tibble containing all the case types present in the OJO
database

## Usage

``` r
ojo_case_types(..., .con = NULL)
```

## Arguments

- ...:

  Placeholder for additional arguments

- .con:

  The OJO database connection to use.

## Value

Tibble of case types

## Examples

``` r

if (FALSE) { # \dontrun{
ojo_case_types()
} # }
```
